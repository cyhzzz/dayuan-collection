## 📖 项目简介

大元藏馆是一个展示天台县资深收藏家「大元」珍贵藏品的网站。收藏领域涵盖玉器、瓷器、铜器、木器花板、钱币等多个类别，尤其专注于天台山文化相关的历史文物。

- **藏品数量**：294 件
- **图片来源**：抖音用户「大元」主页作品
- **数据存储**：Supabase
- **技术栈**：HTML / CSS / JavaScript（原生）
